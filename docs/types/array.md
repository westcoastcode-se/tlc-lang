# Arrays

An array length is a positive decimal `i32` literal. `[_]i32{10, 20, 12}` writes the values. `_` stands for the length, which is the number of values, so the type is `[3]i32`. A file-scope array takes the same lists, including a struct element: `var named [3]i32 = {10, 4, 1}`, `var row = [_]i32{10, 20, 12}`, and `var origin = [_]Point{Point{.x = 1, .y = 2}}`.

A list may be shorter than a written length. `var row [3]i32 = {10, 20}` names two elements. The element it does not name stays uninitialized. Reading it, `return {10, 20}` when the result is `[3]i32`, and `const row [3]i32 = {10, 20}` are reported as `uninitialized`. `0...` at the end of the list stores 0 in every element the list does not name. `var row [4]i32 = {10, 20, 0...}` and `return {10, 20, 0...}` when the result is `[4]i32` are that form. A complete list stores only the values it names. A file-scope array with no initializer is zero. A file-scope shorter list, and a file-scope list that ends with `0...`, is reported as `global initializer is not a constant` when code is emitted. `--check` accepts that list.

An element that is an array is another brace list, or a value of that array. `var row [2][3]i32 = {{1, 2, 3}, {4, 5, 6}}` stores those values, and `row[1][2]` is 6. `var inner [2]i32 = {1, 2}` then `var row = [_][2]i32{inner}` copies `inner`. `{a, b}` copies both rows when `a` and `b` are `[2]i32`. `grid[1]` and `give()` copy that row the same way. A later store into the source does not change the copy. A different length, `[_][3]i32{inner}`, is reported as `type mismatch: expected [3]i32, found [2]i32`. A parameter `[2]i32` in that list copies the array. A later store into the parameter does not change the copy. A different length, `[_][3]i32{row}`, is reported as `type mismatch: expected [3]i32, found *i32`. `var grid = [_][2][3]i32{{{1, 2, 3}, {4, 5, 6}}}` is one outer element of `[2][3]i32`, and `grid[0][1][2]` is 6. `{[_]i32{1, 2, 3}, [_]i32{4, 5, 6}}` writes the same rows. A different count is reported as `type mismatch`. `[_][]i32{{1, 2}, {3}}` is reported as `type mismatch`.

func add4(p *i32) i32 {
    return p[0] + p[1] + p[2] + p[3];

## Cost

Reading an element is reported as `uninitialized`. `row.len` is the constant element count. `func main() i32 { var row [3]i32; return row.len; }` executes 2 instructions, `movl $3, %eax` and `retq`.
