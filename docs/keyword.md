# Keywords

[Index](README.md) · [Previous: Type aliases](types/alias.md) · [Next: Expressions](expressions/operator.md) · [Cost](cost.md) · [Grammar](grammar.md)

Beyond C, `import`, `export`, `package`, `trait`, `func`, `defer`, `var`, and `type` are keywords. `impl`, `from`, `as`, and `this` are identifiers. The full list is in the [grammar](grammar.md#tokens).

## Cost

A keyword is a token. It adds no instructions.
